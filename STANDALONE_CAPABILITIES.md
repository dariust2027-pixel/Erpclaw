# Standalone Offline ERP Branch

This branch is an **offline-first Android ERP prototype**. It saves a company, customers, inventory items, invoice drafts, issued invoices, payments, and balanced journal lines in device-local application storage. It requires no gateway, server, OpenClaw, Hermes, or internet connection.

| Preserved locally | Intentionally not claimed |
|---|---|
| Company setup, customer records, item stock, invoices, payment recording, local double-entry journal lines, sales/cash/receivable/inventory summaries | Full ERPClaw module catalog, statutory reporting, multi-user concurrency, cross-device sync, agent chat, server-side audit controls, tax/payroll/advanced accounting engine parity |

> This branch is a useful standalone operational ledger for offline use and prototyping. It is not presented as a drop-in replacement for the original audited ERPClaw Python engine.
